# CS2_MOLAVE-FA1 #
# Distance Calculation #

## Description ##
This program helps people easily calculate total distance in under 4 values and can be easily edited to compensate for more values

## How to Run ##
1. Open the program.
2. Run the program.
3. Enter the required values on all 4 different value slots(X1,Y1,X2,Y2)

## Input Needed ##
- User must use whole numbers

## Sample Output ##
what is the value of X1? 5
What is the value of Y2? 1
What is the value of X2? 1
What is the value of Y2?1
the total distance is 8 or something
